WebGL2 GPU Engine / Zero Layout Flash / 60 FPS

GPU-accelerated theme transitions.

Replaces harsh opacity cuts with procedural ink-bleed, watercolor bloom, smoke, and liquid wavefronts. Runs entirely on the GPU via fragment shaders and lightweight viewport snapshotting.

$ npm i theme.changer

Mechanism Comparison

Why traditional CSS transitions fail on complex applications.

Traditional CSS Opacity Transition
  • Mid-transition contrast drop: Text becomes washed out and unreadable while opacity blends.
  • Incoherent DOM redraw: Background and foreground elements blend at different rates, producing a cloudy gray flash.
  • No origin awareness: The transition happens uniformly everywhere, disconnected from user interaction.
theme.changer Radial SDF Shader
  • Zero readability loss: Text remains 100% crisp on both sides of the moving frontier.
  • Organic wave propagation: Spreads from the exact button or coordinate clicked by the user.
  • Interruptible: Clicking mid-spread freezes the current GPU frame and propagates the next layer without glitching.

Installation & Integration

Install from npm and initialize with three lines of code.

npm / pnpm / yarn / bun
npm install theme.changer gsap html2canvas 
import { createInkTransition } from 'theme.changer';

// Mount the WebGL2 transition engine on your toggle element
const ink = createInkTransition({
  toggleButton: document.querySelector('#theme-toggle'),
  preset: 'ink', // 'ink' | 'watercolor' | 'smoke' | 'ember' | 'ripple'
  captureMode: 'viewport', // fast ~30ms snapshotting
  captureOnToggle: true, // snapshot on demand at toggle
  onToggle: (theme) => console.log(theme),
});

// Trigger dynamically from any button click or mouse position
button.addEventListener('click', (e) => {
  ink.toggle({ x: e.clientX, y: e.clientY });
});
import { useEffect, useRef } from 'react';
import { createInkTransition, type InkTransition } from 'theme.changer';

export function useThemeChanger() {
  const inkRef = useRef<InkTransition | null>(null);

  useEffect(() => {
    inkRef.current = createInkTransition({
      toggleButton: document.querySelector('#theme-toggle') as HTMLButtonElement,
      preset: 'ember',
      captureMode: 'viewport',
      captureOnToggle: true,
    });
  }, []);

  const toggleTheme = (e?: React.MouseEvent) => {
    if (e) {
      inkRef.current?.toggle({ x: e.clientX, y: e.clientY });
    } else {
      inkRef.current?.toggle();
    }
  };

  return { toggleTheme, ink: inkRef.current };
}

API Reference

Methods and configuration options exposed by the engine.

TypeScript Definitions
Property / Method Type Default Description
createInkTransition(opts?) (options?: Options) => InkTransition - Initializes and mounts the WebGL canvas and context listeners.
ink.toggle(point?, seed?) (point?: Point, seed?: Seed) => void toggleCenter() Triggers the radial expansion from the specified viewport CSS coordinate.
ink.setPreset(name) (name: PresetName) => void 'ink' Switches live shader parameters (duration, tendril, noiseScale, softness, drift).
ink.setCaptureMode(mode) (mode: 'viewport' | 'full') => void 'viewport' Configures snapshotting strategy: viewport (~30ms) or full document.
ink.replay() () => boolean - Re-runs the previous click using the identical seed and origin coordinates.
